# Chat Context Logs

This directory contains markdown context summaries for each chat conversation session.

## Naming Convention

- **Format**: `YYYY-MM-DD-<short-topic-description>.md`
- **Example**: `2026-09-13-tsconfig-ignore-deprecations-fix.md`

## Structure of Each Log

Each markdown file should document:
1. **Date & Title**: When the session occurred and its main objective.
2. **Key Issues / Requests**: What was requested or diagnosed.
3. **Actions Taken**: Specific file modifications, commands executed, or solutions implemented.
4. **Verification**: How the changes were tested and verified.
5. **Current State / Next Steps**: Summary of the codebase state post-session.
